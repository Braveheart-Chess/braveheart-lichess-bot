# braveheart-lichess-bot

The Lichess bot for [Braveheart](https://github.com/Braveheart-Chess/braveheart),
the UCI chess engine: its [lichess-bot](https://github.com/lichess-bot-devs/lichess-bot)
configuration and the script that runs it. The engine repository holds only the
engine; everything that connects it to Lichess lives here.
